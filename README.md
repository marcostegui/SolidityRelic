# SolidityRelic

SolidityRelic is a blockchain-agnostic, modular framework for scalable smart contract execution and intelligent contract relic management.

With SolidityRelic, you get a lightweight tool that stays out of your way.

**What you get**

- SolidityRelic is a blockchain-agnostic, modular
- framework for scalable smart contract
- execution and intelligent contract relic

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/SolidityRelic.git`
2. `cd SolidityRelic`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure SolidityRelic, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
